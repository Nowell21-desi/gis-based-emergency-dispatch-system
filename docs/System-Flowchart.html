2. Citizen: Send SOS and Track the Request

flowchart TD
    A([Citizen opens SOS screen]) --> B[Location detected from GPS]
    B --> C[Enter description and optional photo]
    C --> D{Internet connected?}
    D -- No --> E[Saved in offline queue on the device]
    E --> F[Sent automatically when connection returns]
    D -- Yes --> G[SOS sent to server]
    F --> G
    G --> H[Incident created with status Pending Verification]
    H --> I[Citizen sees live status]
    I --> J{What does the citizen do?}
    J -- Adds information or scene photo --> K[Sent to dispatch while the request is open]
    K --> I
    J -- Cancels an open request --> M[Status becomes Cancelled]
    J -- Request is Resolved or Closed --> N[Action buttons hidden]
    J -- Waits --> I

3. Dispatcher: Triage, Verify, and Assign

flowchart TD
    A([Dispatcher signs in]) --> B[Live incident queue and map]
    B --> C[Select an incident]
    C --> D[Verify Call: incident details panel opens]
    D --> E{Status allows verification?}
    E -- Yes --> F[Verify call and open for dispatch]
    E -- No --> G[Details only]
    F --> H[Assign Unit: nearby units listed by distance and GPS freshness]
    G --> H
    H --> I[Choose unit and confirm dispatch]
    I --> J[Responder notified]
    J --> K{Responder response}
    K -- Accepts --> L[Incident Assigned / Accepted]
    K -- Declines --> H
    L --> M[Other actions: notify team, false alarm, cancel, reopen]
    M --> N[Timeline and report kept]

4. Responder: Duty, Assignment, and Navigation

flowchart TD
    A([Responder signs in]) --> B[Time in]
    B --> C[Status Available]
    C --> D[GPS shared about every second]
    D --> E{Assignment received?}
    E -- No --> D
    E -- Yes --> F[Accept or decline]
    F -- Decline --> C
    F -- Accept --> G[Navigate: route from GPS to scene]
    G --> H[Status En Route]
    H --> I[Status On Scene]
    I --> J{Patient transported?}
    J -- Yes --> K[Transporting, then At Hospital]
    J -- No --> L[Resolved]
    K --> L
    L --> M[Submit incident report]
    M --> N[Status Available]
    N --> O{End of shift?}
    O -- No --> D
    O -- Yes --> P[Time out: blocked while on an assignment]
    P --> Q[Status Off Duty]
